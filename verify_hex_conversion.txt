Verification of hex_to_colorref Implementation
==============================================

Function Purpose:
- Convert hex color (#RRGGBB) to Windows COLORREF format (0x00BBGGRR)
- Windows uses BGR (Blue-Green-Red) order, not RGB

Implementation Logic:
1. Validate input starts with '#'
2. Validate input length is exactly 7 characters
3. Parse R, G, B components from hex string
4. Convert to BGR DWORD: (B << 16) | (G << 8) | R

Test Cases Verification:

  Result: (0 << 16) | (0 << 8) | 255 = 0x000000FF ✓
